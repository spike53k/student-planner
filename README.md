# Планировщик учебных задач
Удобное приложение для отслеживания дедлайнов и домашних заданий.

Возможности:
* Добавление новых учебных задач
* Изменение статуса выполнения
* Сортировка по приоритету

Текущая версия проекта: 1.0

# Целевая аудитория
Студентов вузов и колледжей, которым сложно удерживать в голове расписание и сроки сдачи лабороторных работ.

## Принципы использования
* Простота - управление через консоль без лишних кнопок.
* Скорость - добавление задачи одной командой.
